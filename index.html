Калькулятор покупки

Налог на купоны удерживает брокер автоматически. Дисконт (разница цены покупки и номинала) при погашении по номиналу НДФЛ не облагается. Даты купонов считаются с шагом COUPONPERIOD от следующего купона — для бумаг с неровным графиком возможна погрешность ±1 купон. Суммы — на одну бумагу номиналом 1000 ₽. Не является инвестиционной рекомендацией.

Данные: ISS API Мосбиржи · сервис бесплатный · не является инвестиционной рекомендацией
